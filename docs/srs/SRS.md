## 1. 목적·범위·용어

### 1.1 목적

이 문서는 RFP에서 태어난 `FR-<COMP>-NN`·`NFR-<COMP>-NN`을 **같은 번호로 유지한
채** 관찰·측정·판정 가능한 문장으로 정련하고, 각 요구에 검증 유형을 붙인다.
새 요구 번호를 만들지 않는다.

### 1.2 문서 경계

| 내용 | 소유 문서 |
|---|---|
| 요구의 존재와 우선순위, 범위·비범위 | RFP |
| 사용자 스토리와 수용 조건 | PRD |
| **수치 합격선과 승인 상태** | 본 문서 §3 |
| 구조·저장 기술·모듈 구성·기술 선택 이유 | SDD |
| 시험 절차·시험 자료·Pass/Fail 전개 | TC |

### 1.3 규범 용어

| 용어 | 의미 |
|---|---|
| SHALL (~해야 한다 / ~해서는 안 된다) | 충족 필수. 미충족은 요구 위반이다 |
| SHOULD (~하는 것을 목표로 한다) | 목표. 제약으로 조정 가능하며 조정 사실을 기록한다 |
| MAY (~할 수 있다) | 선택. 미제공이 위반이 아니다 |

평서문("~한다")은 요구가 아니라 설명이며 §2·§3의 요구 표에 넣지 않는다.

### 1.4 핵심 용어집

| 용어 | 정의 |
|---|---|
| **기록 후보** | 자동 해석 또는 반복 항목으로부터 생성되어 사용자의 확인을 기다리는 미확정 자료. 조회·요약·합계의 대상이 아니다 |
| **확정 기록** | 사용자의 확인 동작을 거쳐 저장된 자료. 조회·요약·합계의 유일한 대상이다 |
| **확인 동작** | 사용자가 기록 후보의 내용을 받아들여 확정 기록으로 만드는 명시적 입력. 화면을 열어 보는 것은 확인 동작이 아니다 |
| **거래 방향** | 기록이 수입인지 지출인지의 구분. 값은 수입·지출·미확정 셋 중 하나다 |
| **분류** | 사용자가 소유하는 기록의 분류 단위. 고유 식별자와 이름을 가지며 이름은 변경 가능하다 |
| **분류 집합** | 특정 시점에 사용자가 보유한 모든 분류의 집합 |
| **태그** | 분류의 **화면 표기 이름**. 요구 문서는 '분류'로 쓰고 화면은 '태그'로 보여 준다. 같은 것을 가리키며, 이 표가 둘의 유일한 대응표다(SDD ADR-012) |
| **거래 대상** | 입력에서 추출된, 돈이 오간 상대를 가리키는 문자열(상호명 등). `FR-CAT-07`의 판정 기준이다 |
| **미확정 항목** | 해석이 값을 정하지 못한 항목. 값이 비어 있는 것과 구분되며, 그 사실이 기록 후보에 표시된다 |
| **반복 항목** | 사용자가 등록한, 주기와 기준일을 가진 지출·수입의 정의. 그 자체는 확정 기록이 아니다 |
| **예산** | 분류와 기간을 지정해 저장된 금액 상한 |
| **근거 이미지** | 기록 후보의 생성에 쓰인 이미지. 확정 기록에 참조로 연결된다 |
| **외부 해석 수단** | 입력의 해석을 수행하는, 제품 밖에서 동작하는 처리 주체 |
| **첫 진입 지점** | 사용자가 제품에 접근했을 때 최초로 도달하는 지점 |
| **반출 파일** | 확정 기록 전체를 담아 제품 밖으로 내보낸 파일 |
| **삭제된 기록** | 삭제 요청으로 조회·요약 대상에서 제외되었으나 복원 가능한 상태로 보존된 기록 |

## 2. 기능 요구사항

RFP §5와 같은 그룹 구성을 유지한다. 번호는 RFP와 동일하며, 추가된 것은 관찰
지점과 검증 유형이다.

## 4. 시스템 불변조건

어떤 구현에서도 깨지면 안 되는 규칙이다.

1. **확정 기록은 확인 동작을 거친 것만 존재한다.** 확인 동작 없이 생성된 확정
   기록이 존재하면 불변조건 위반이다. (`FR-ENTRY-05`)
2. **조회 결과 0건은 거래의 부재가 아니다.** 시스템은 0건을 부재로 환산해
   표시하거나 계산의 전제로 삼아서는 안 된다. (`FR-VIEW-07`)
3. **자동 배정된 분류는 항상 분류 집합의 원소다.** 분류 집합 밖의 값이 자동
   배정 결과에 나타나면 위반이다. (`FR-CAT-06`)
4. **기록의 분류 귀속은 분류 자체의 변경으로 소실되지 않는다.** 이름 변경·삭제는
   귀속 관계를 끊지 못한다. (`NFR-CAT-01`)
5. **외부 전송은 입력 해석 요청에서만 발생한다.** 그 밖의 처리에서 발생한 외부
   전송은 위반이다. (`FR-ENTRY-15`)
6. **외부 해석 수단의 가용성은 직접 입력 경로의 가용성을 좌우하지 않는다.**
   (`FR-ENTRY-14`)
7. **기록 후보는 집계의 대상이 아니다.** 합계·요약·예산 대비의 계산에 기록
   후보가 포함되면 위반이다. (§1.4 용어 정의)

## 5. 인터페이스 계약

기능군 수준의 계약이며, 정확한 호출 형태와 항목 이름은 SDD가 소유한다.

| 기능군 | 행위자 | 입력·validation | 성공의 의미 | 오류의 의미 |
|---|---|---|---|---|
| 입력 해석 | 가계부 작성자 | 자연어 문자열 또는 이미지. 비어 있으면 거부한다 | 하나 이상의 기록 후보가 반환됐다. 확정된 것은 없다 | 해석 불가: 후보를 만들지 못했다(입력은 보존된다) / 외부 수단 실패: 지금 해석할 수 없다(입력은 보존된다) |
| 기록 확정 | 가계부 작성자 | 기록 후보와 확인 동작. 날짜·금액·거래 방향·분류가 모두 정해져야 한다 | 확정 기록이 저장돼 조회·요약의 대상이 됐다 | 미확정 항목 존재: 어떤 항목이 비었는지 알린다. 부분 저장은 하지 않는다 |
| 기록 정정 | 가계부 작성자 | 대상 기록의 식별자와 바꿀 항목 값 | 저장된 값이 갱신돼 이후 조회·요약에 반영된다 | 대상 없음: 그 식별자의 기록이 없다 / 값 부적합: 원래 기록은 훼손되지 않는다 |
| 기록 삭제·복원 | 가계부 작성자 | 대상 기록의 식별자 | 삭제: 조회·요약에서 제외된다(보존은 유지) / 복원: 삭제 직전 값으로 돌아온다 | 대상 없음: 삭제 또는 복원할 기록이 없다. 다른 기록은 바뀌지 않는다 |
| 분류 관리 | 가계부 작성자 | 분류 이름 또는 식별자. 삭제 시 귀속 기록 유무를 확인한다 | 분류 집합이 갱신되고 기존 귀속은 보존된다 | 귀속 기록 존재: 추가 확인 없이는 삭제하지 않는다 / 이름 중복: 같은 이름의 분류를 만들지 않는다 |
| 조회·요약 | 가계부 작성자 | 날짜, 기간, 조건 항목 | 조건을 만족하는 확정 기록 또는 그 집계가 반환된다 | 0건: 조건에 맞는 기록을 찾지 못했다(부재가 아니다) / 기간 부적합: 시작이 끝보다 뒤일 수 없다 |
| 예산 | 가계부 작성자 | 분류, 기간, 금액 | 예산이 저장되고 같은 기간의 지출과 함께 조회된다 | 예산 미설정: 대비할 값이 없다(초과가 아니다) |
| 반출·반입 | 가계부 작성자 | 반출: 없음 / 반입: 반출 형식의 파일 | 반출: 전체 확정 기록이 담긴 파일이 만들어졌다 / 반입: 파일의 기록이 확정 기록이 됐다 | 형식 불일치: 반입하지 않는다. 기존 기록은 훼손되지 않는다 / 대상 없음: 반출할 기록이 없다(실패가 아니다) |

## 6. 상태·오류·빈 결과의 의미

| 상황 | 시스템 판정 | 사용자에게 표시할 의미 | 금지되는 해석 | 가능한 다음 행동 |
|---|---|---|---|---|
| 입력 해석 결과의 일부 항목이 정해지지 않음 | 미확정 항목 있음 | 어떤 항목이 정해지지 않았는지 | 해석 실패로 단정 / 임의 값으로 채움 | 비어 있는 항목을 채워 확인한다 |
| 입력에서 어떤 항목도 정해지지 않음 | 해석 불가 | 입력에서 기록할 내용을 찾지 못함 | 입력이 잘못됐다고 단정 / 기록할 것이 없다고 단정 | 직접 입력으로 이어받는다 |
| 이미지에서 어떤 항목도 정해지지 않음 | 해석 불가 | 이미지에서 읽어 내지 못함 | 이미지가 잘못됐다고 단정 / 그 이미지에 거래가 없다고 단정 | 직접 입력으로 이어받거나 다른 이미지를 준다 |
| 외부 해석 수단이 응답하지 않음 | 해석 수단 사용 불가 | 지금 자동 해석을 쓸 수 없음 | 기록이 불가능하다고 표시 / 입력을 폐기 | 직접 입력으로 기록한다 |
| 확인 동작 없이 이탈 | 후보 미확정 | 아직 기록되지 않음 | 저장된 것으로 표시 | 돌아와 확인하거나 버린다 |
| 조회·검색 결과 0건 | 조건 일치 없음 | 조건에 맞는 기록을 찾지 못함 | **그 기간에 거래가 없었다고 단정** / 합계 0을 "안 씀"으로 단정 | 조건을 바꾸거나 기록을 남긴다 |
| 비교할 기간이 하나뿐 | 비교 불가 | 비교할 기간이 부족함 | 변화가 없다고 단정 | 기간을 넓힌다 |
| 예산이 설정되지 않음 | 대비 대상 없음 | 이 분류·기간에 예산이 없음 | **예산 초과로 표시** / 예산 0으로 계산 | 예산을 정한다 |
| 귀속 기록이 있는 분류의 삭제 시도 | 확인 필요 | 그 분류에 기록이 남아 있음 | 확인 없이 삭제 / 귀속 기록을 함께 삭제 | 확인 후 진행하거나 그만둔다 |
| 삭제 후 복원 대상 없음 | 대상 없음 | 되살릴 기록이 없음 | 다른 기록을 복원 | 그만둔다 |
| 반입 파일의 형식 불일치 | 반입 불가 | 이 파일로는 반입할 수 없음 | 부분 반입 / 기존 기록 훼손 | 다른 파일로 시도한다 |
| 반출할 기록 없음 | 대상 없음 | 반출할 기록이 없음 | 반출 실패로 표시 | 기록을 남긴 뒤 반출한다 |

**금지되는 해석의 근거** — 이 제품은 "아직 기록되지 않은 지출이 존재한다"는
전제 위에 있다(MRD §2). 0건을 부재로 환산하는 순간 사용자의 판단이 왜곡되므로,
이는 표시 문제가 아니라 §4 불변조건 2의 문제다.

## 7. 데이터 논리 계약

저장 기술과 무관하게 보존되어야 하는 식별·귀속·참조 관계다. 물리 스키마·색인은
SDD가 소유한다.

| 자료 | 보존해야 하는 것 |
|---|---|
| 확정 기록 | 고유 식별자 · 날짜 · 금액 · 거래 방향 · 분류 참조 · 사용자가 적은 내용 · 근거 이미지 참조(없을 수 있음) · 확정 시각 |
| 기록 후보 | 확정 기록과 **분리된 자료**로 존재하며, 항목별로 값 또는 미확정 표시를 가진다. 확정 기록의 식별자를 가지지 않는다 |
| 분류 | 고유 식별자 · 이름 · 적용되는 거래 방향 |
| 기록→분류 참조 | **이름이 아니라 식별자로 유지된다.** 이름이 바뀌어도 참조가 끊기지 않아야 한다(`NFR-CAT-01`) |
| 삭제된 기록 | 삭제 표시와 삭제 직전의 모든 항목 값. 되살리기가 값을 재구성하지 않고 복원할 수 있어야 한다(`FR-ENTRY-11`) |
| 반복 항목 | 고유 식별자 · 주기 · 기준일 · 생성할 기록의 내용. 반복 항목과 그로부터 확정된 기록은 서로 다른 자료다 |
| 예산 | 분류 참조 · 기간 · 금액. 예산의 부재와 금액 0은 서로 다른 상태다 |
| 분류 변경 이력 | 거래 대상 문자열 · 사용자가 선택한 분류 참조 · 기록 시각. `FR-CAT-07`의 판정 근거이며, 같은 거래 대상에 대해 가장 나중의 것이 우선한다 |
| 근거 이미지 | 확정 기록당 하나 이하로 연결된다. 이미지의 삭제가 기록의 다른 항목을 훼손해서는 안 된다 |

## 8. 비목표와 호환 경로

- **현재 요구가 아닌 것** — RFP §3.2의 비범위를 그대로 따른다. 이 문서는 비범위를
  새로 만들지 않는다.
- **호환 경로** — 이전 버전이 없는 최초 명세이므로 과거 호환 대상이 없다. 반출
  파일의 형식은 `FR-VIEW-11`이 자신이 만든 형식만 반입하도록 한정하므로, 형식이
  바뀌면 그 시점의 이전 형식에 대한 처리 방침을 이 절에 추가한다.
